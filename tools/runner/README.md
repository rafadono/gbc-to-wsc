# WonderSwan Color Desktop Runner Directory

Place your WonderSwan Color executable runner (e.g. `mednafen.exe`, `Mesen.exe`, or custom test harness) in this directory.

The automated pipeline and test scripts will auto-detect any executable in this folder to run and validate generated `.wsc` binaries.

Supported runners:
* `mednafen.exe`
* `Mesen.exe`
* Any custom WonderSwan executable runner (*.exe)
